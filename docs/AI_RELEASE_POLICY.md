# Menschliche Release-Freigabe

Automatisierte Agenten dürfen nur eigene Branches und Entwurfs-Pull-Requests erstellen.
Kein Agent darf einen PR automatisch mergen, Versions-Tags setzen, veröffentlichen oder `leitstelle-deutschland-release` verändern.
Erst eine nachgewiesene Abnahme von Browser, iPad, Windows, Speicherung, Audio, Leistung und Lizenzen und eine ausdrückliche Freigabe erlauben eine Veröffentlichung.
Bekannte Integration ist kein bereits abgenommener 1.0-Release.
