# LEITSTELLE DEUTSCHLAND – Publikationszweig

Dieser Zweig enthält ausschließlich die eigenständige Web-App LEITSTELLE DEUTSCHLAND v0.21 als ZIP-Paket. Der produktive ATC-Hauptzweig bleibt unverändert.

Render: Static Site, Build Command: `mkdir -p public && unzip -q -o LEITSTELLE_DEUTSCHLAND_v0_21.zip -d public`, Publish Path: `public`.

Die PWA ist eine fiktive Simulation; Wachen, Gebietszuschnitte und Einsätze sind teilweise vereinfachte Modelle.
